Build the daily utilisation report in Power Automate

Every weekday morning, one flow reads yesterday's hours from Clockify, matches people to their Team Leads using your Excel mapping, works out each person's utilisation and posts a separate report in each Team Lead's Teams channel. After setup, you only maintain the Excel file.

Build time
About 2 hours, once
Runs
Mon–Fri, 9:00
Clockify calls
2 per run
Licence
Only the flow owner

The pictures in this guide are drawings of each screen, not screenshots. Microsoft updates Power Automate often, so a label or button on your screen may look slightly different.

HOW IT WORKS

One flow, five stages

Schedule

Starts itself every weekday at 9:00. Monday's run reports on Friday.

Clockify

Gets everyone's hours for the report day, split by project.

Excel

Reads who reports to whom, daily hours, leave and each TL's channel.

Calculate

Hours, capacity, utilisation % and a status for each person.

Teams

Posts one report in each Team Lead's channel.

Utilisation = Logged hoursCapacity × 100
Clockify sends time in seconds: 23,400 s ÷ 3,600 = 6.5 h logged Capacity = Daily Hours in Excel (blank = 8 h), or 0 h when the person is on leave 6.5 h ÷ 8 h × 100 = 81% → On track

The 80% and 110% limits are settings you can change in one place (step C2).

0 · BEFORE YOU START

Check you have these

  • Power Automate Premium trial is active. Open make.powerautomate.com. If the trial is active, the HTTP action (step A3) does not show a "Premium" upgrade prompt.
  • Admin (or Owner) role in Clockify. Clockify only gives the API the hours you can see in its Reports page. With a normal member role, the report would contain only your own hours.
  • A place for the Excel file in OneDrive for Business or a SharePoint site that only the PMO team can open.
  • A test channel in Teams, for example "Utilisation – Test" in a team only you are in. You'll send test reports there before anything reaches the Team Leads.
  • An OK from IT. Your company's data-security rules apply when you connect Clockify to Microsoft 365. Ask IT to confirm that the HTTP connector is allowed in your company's Power Automate data policy (if it isn't, saving the flow shows a "data policy" error).
PART A · ABOUT 15 MINUTES

Connect Clockify

This is the connection test from your plan, plus one extra: noting your Workspace ID, which every later step needs.

A1

Copy your Clockify API key

  1. In Clockify, click your profile picture (top right) and open Preferences (called Profile settings in older versions).
  2. Open the Advanced tab and find API key. Click Generate and copy the key.
  3. Keep it somewhere private for the next 30 minutes, such as a password manager. Don't email it or paste it into a chat.
Why it mattersThe key opens your Clockify account. In Power Automate you'll hide it with Secure inputs, so it never shows in run history.
A2

Find your Workspace ID

  1. In Clockify, open the workspace Settings page.
  2. Look at the address bar. The Workspace ID is the long code between /workspaces/ and /settings.
  3. Save it in a note. You'll paste it into two web addresses in Part C.
https://app.clockify.me/workspaces/64f1c2a9b7e3d10f5a2c88e1/settings
Workspace ID (example)

If you can't spot it, the test in A3 also returns it: it's the id next to your workspace name.

A3

Run the connection test

  1. In Power Automate: Create → Instant cloud flow → name it "Clockify test" → choose Manually trigger a flow → Create.
  2. Click + under the trigger, search for HTTP and pick the action called just HTTP (not "HTTP with Microsoft Entra ID").
  3. Fill it in as shown below. Under Headers, type X-Api-Key on the left and paste your API key on the right.
  4. Open the action's Settings tab and switch on Secure inputs.
  5. Save → Test → Manually → Test → Run flow.
URItype or paste as text
https://api.clockify.me/api/v1/workspaces

Success looks like this: the HTTP step has a green tick, Status code 200, and the body lists your workspace:

Example result
[
  {
    "id": "64f1c2a9b7e3d10f5a2c88e1",
    "name": "Your Company Workspace",
    ...
  }
]

A 401 means the key is wrong or has a typo. Check the header name is exactly X-Api-Key. You can delete this test flow once it works.

PART B · ABOUT 20 MINUTES

Prepare the Excel file

The flow reads three Excel tables by name. Start from the template file Utilisation-Mapping-Template.xlsx, which has the tables already set up, and copy your existing TL–Resource mapping into it.

B1

Put the template in OneDrive or SharePoint

  1. Upload Utilisation-Mapping-Template.xlsx to a OneDrive for Business or SharePoint folder that only the PMO team can open. Rename it if you like, for example "Utilisation Mapping.xlsx".
  2. Open it in Excel for the web. You'll see five sheets: Read me, Resources, TeamLeads, Leave and History.
Keep these namesDon't rename the tables or their column headings. The flow looks for them by name. You can rename the file and the sheets.
B2

Fill in Resources

Replace the example rows with your mapping, one row per person.

ColumnWhat to enter

  1. In Teams, go to the channel where a TL's report should appear.
  2. Click ⋯ (More options) next to the channel name → Copy link (older Teams: Get link to channel → Copy).
  3. Paste it into the Channel Link column next to the TL's name.

B4

Add leave and public holidays

  • One row per leave period: Email, From, To (both dates required; for one day, use the same date twice) and an optional Note.
  • People on leave show as 🌴 On leave and don't count towards team capacity.
  • For a public holiday, type ALL in the Email column. The flow then sends no report for that day.
PART C · ABOUT 75 MINUTES

Build the daily flow

Follow the steps in order. Every formula is ready to copy, so there's nothing to write yourself. This is the finished flow you're building:

Three things you'll do over and over

  1. Add an action: click + where it should go → Add an action → search for its name.
  2. Rename it straight away: click the action's title in the side panel and type the new name. Formulas refer to actions by name, so use the exact names in this guide.
  3. Paste a formula: click in the field → click the fx icon (Insert expression) → paste → Add. It appears as a purple token.

How to read the formula boxes

  • paste with fx goes in through the fx button, never typed straight into the field.
  • type or paste as text goes straight into the field.
  • Save often. If a step won't save, check the action names match this guide exactly, including capital letters.

TROUBLESHOOTING

When a step turns red

Open the failed run, click the red step and read its output. Most problems are one of these.

What you seeWhat it means and how to fix it
HTTP 401The API key is wrong or was regenerated. Paste the current key into both HTTP actions.
HTTP 403Your Clockify role can't see other people's time. Ask the Clockify owner to make you an Admin.
HTTP 404The Workspace ID in the URI is wrong. Copy it again (A2).
HTTP 429Too many Clockify calls in an hour (free plan limit: 30). Wait an hour and run again.
"Data policy" or "DLP" error when savingYour company's Power Automate rules don't allow HTTP together with Excel or Teams. Ask IT to allow it for this flow.
Excel: table not foundA table was renamed. In Excel: click inside the table → Table Design → Table Name, and set it back.
Error mentioning 'Daily Hours', 'Team Lead' or 'Email'A column heading in Excel was changed. Put the exact heading back.
Everyone shows ❓ Not in ClockifyOpen the Get Clockify users output. If it's empty, check the Workspace ID. If the emails there differ from Excel, fix Excel. If your workspace has more than 500 members, ask for help adding a second page.
A TL got an empty tableTheir name in TeamLeads doesn't match the Team Lead column in Resources (check spelling and extra spaces).
Teams step fails: channel not foundThe Channel Link isn't a channel link (perhaps a message link), or the channel is private. For private channels, change Post as to User.
Flow didn't run at allIt was turned off, or the trial ended (see below). Check My flows.
